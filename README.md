# Debloat-X
Debloat X is an android application developed to disable, uninstall, or debloat all applications (including system application). This app requires your device to be rooted to work.

Features:
√Toggles to search by package name and search by app name
√Multi Select
√Uninstall App
   •Including app data
   •Excluding app data
√Disables and Enables Applications
√Detects App State
√Universal(Works on other devices)
√Added Support to A12
